Cài đặt

        
      

      

        

          
          
          
        


        

          

            Tại sao cần cookie? Story, video riêng tư, nhóm kín, tài khoản private… chỉ xem được khi đăng nhập.
            VidGrab dùng cookie của chính tài khoản bạn để tải những gì tài khoản đó được phép xem. Cookie chỉ lưu trên máy bạn.
          


          
Cách 1 · Nạp file cookies.txt (khuyên dùng)

          


          
Cách 2 · Đọc cookie trực tiếp từ trình duyệt

          

            
            Dùng khi chưa nạp file. Firefox hoạt động ổn định nhất; Chrome/Edge cần đóng trình duyệt trước khi tải.
          

        


        

          
Thư mục lưu

          
          
Mẫu tên file

          
          
Ví dụ: %(uploader)s - %(title)s [%(id)s].%(ext)s · Bỏ [%(id)s] nếu muốn tên gọn (file trùng tên sẽ bị ghi đè).

Hướng dẫn tải nội dung riêng tư & story

        
      

      

        
    
          
  1. 
            Cài extension xuất cookie cho trình duyệt:
            Get cookies.txt LOCALLY (Chrome/Edge/Cốc Cốc) hoặc
            cookies.txt (Firefox).
          
    2. 
          
  2. Đăng nhập Facebook / Instagram / TikTok / YouTube bằng tài khoản có quyền xem nội dung đó (đã follow, đã vào nhóm…).
    3. 
          
  3. Mở trang của nền tảng đó → bấm icon extension → Export → lưu file .txt.
    4. 
          
  4. Trong VidGrab: Cài đặt → Cookie → bấm Nạp file ở đúng nền tảng (hoặc kéo-thả file vào ô).
    5. 
          
  5. Dán link story / video riêng tư và bấm Phân tích. Xong!
    6. 
        

        
📱 Trên điện thoại Android

        
    
          
  • Lấy cookie: cách dễ nhất là xuất file cookies.txt trên máy tính (các bước ở trên) rồi gửi sang điện thoại qua Zalo / Drive / cáp, sau đó vào Cài đặt → Cookie → Nạp file và chọn file đó.
    • 
          
  • Hoặc dùng Firefox cho Android, cài add-on xuất cookie (vd. cookies.txt), đăng nhập rồi xuất file ngay trên điện thoại.
    • 
          
  • Tải nhanh: trong TikTok / Facebook / Instagram / YouTube bấm Chia sẻ → VidGrab (sau khi đã cài app ra màn hình chính) hoặc Chia sẻ → Termux. VidGrab sẽ mở và tự phân tích link.
    • 
          
  • File lưu ở Download/VidGrab, xem bằng ứng dụng Tệp, Thư viện ảnh hoặc trình phát nhạc.
    • 
        

        
Link mẫu được hỗ trợ

        

          
Instagram storyinstagram.com/stories/<username>/ (tải toàn bộ story) hoặc …/stories/<user>/<id>/

          
Instagram reel / post / highlightinstagram.com/reel/…, /p/…, /stories/highlights/<id>/

          
Facebookfacebook.com/…/videos/…, /reel/…, fb.watch/…, /watch/?v=, video trong nhóm

          
TikToktiktok.com/@user/video/…, vt.tiktok.com/…, link share (có kèm chữ cũng được)

          
YouTubeVideo, Shorts, playlist, kênh, video không công khai / thành viên (cần cookie)

        

        

          Lưu ý: Chỉ tải nội dung bạn có quyền xem và tôn trọng bản quyền / quyền riêng tư của người khác.
          Cookie đăng nhập giống như mật khẩu — không chia sẻ file cookie cho ai. Nên dùng tài khoản phụ để tránh bị khoá do tải quá nhiều.
          Facebook story đôi khi không được yt-dlp hỗ trợ — khi đó hãy thử mở story, copy link video trực tiếp.
